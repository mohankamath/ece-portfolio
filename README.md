# Mohan Kamath’s ECE 1100 ePortfolio

This site uses plain HTML, CSS, and local SVG illustrations. Open `index.html` in any browser to preview it. It works from a folder on your computer and from a GitHub Pages project URL.

## Before the Canvas submission

- Review the first-person copy and adjust it to match your experience and voice.
- Your supplied résumé is included as `resume.pdf`. To update it later, replace that file with the same filename.
- Review the published page on a phone and open it in a private browser window. Test the résumé’s view and download links there, then submit the **published site URL** in Canvas.

## Publish on GitHub Pages

1. On GitHub, create a public repository, for example `ece-portfolio`.
2. Put the **contents** of this folder at the root of the repository’s `main` branch. Include `index.html`, `styles.css`, `assets/`, and `resume.pdf`. Keep `.nojekyll` at the root to serve the static files directly. If your upload interface omits the hidden file, create an empty file named `.nojekyll` at the repository root.
3. In your repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. When deployment finishes, open **Visit site** in Pages settings. For the example project repository, the address is usually `https://YOUR-USERNAME.github.io/ece-portfolio/`.

[GitHub’s branch publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Finish the Discovery Project Feature before the showcase

The Musical Instrument article (`id="discovery"` in `index.html`) already has a **400+ word** write-up on the problem, process, and bench-test results. Use the showcase prompts to check that you’ve covered the required questions and add any newer results. Add at least **one photo or video you took or created of the project**. Save it in `assets/` and add it to the article with a short caption and descriptive alternative text for photos, or captions for any spoken video content.

The completed portfolio needs **1,000 words and five visuals** in total. The site already clears both thresholds. The project diagram shows the signal path and the photo or video is a separate showcase requirement. Push the update to the same branch to keep the URL you submitted.
